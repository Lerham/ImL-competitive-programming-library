# 偏角ソート

`000/starter.cpp` を使い、`argument_sort.cpp` の関数を `main` より前に貼り付けます。x 座標と y 座標の配列は、どちらも **1-indexed** で同じサイズにします。
提出時はファイル先頭の出典リンクも含めて貼り付けてください。

```cpp
vector<long long> x = {0, 0, -1, 1, 0};
vector<long long> y = {0, 1, 0, 0, -1};
auto [sorted_x, sorted_y] = argument_sort(x, y);
// 1 番から順に (1, 0), (0, 1), (-1, 0), (0, -1)
```

- 正の x 軸を 0 度とし、反時計回りに並べます。
- `sorted_x[i]` と `sorted_y[i]` は同じ点の座標です。0 番のダミーもそのまま返します。元の配列は変更しません。
- 原点 `(0, 0)` は偏角を持たないため、他の点より先に置きます。同じ偏角の点と複数の原点は、それぞれ入力順を保ちます。
- 座標は `int` や `long long` など 64 bit 以下の符号付き整数に対応します。2 配列は同じ型にしてください。浮動小数点座標には対応しません。
- 整数演算で比較し、計算量は `O(N log N)`、追加メモリは `O(N)` です。`__int128` を使うため、AtCoder の g++ などで利用してください。
