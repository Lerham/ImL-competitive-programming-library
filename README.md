# ImL-competitive-programming-library

ライブラリは基本的に `000/starter.cpp` の include と型定義を前提とし、関数などを `main` より前に貼り付けて使います。
提出時に出典を示せるよう、ライブラリのコードには先頭に公開先の `// Source: https://github.com/...` を付け、コピー時も残します。公開前の変更は公開し、リンク先で内容を確認してから提出します。
