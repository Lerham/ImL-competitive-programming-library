# 木の直径（Tree Diameter）

**木の直径**は、木の任意の2頂点間の距離の最大値。重みなしの場合は「通る辺の本数」で数える。
このコードは **1-indexed（頂点番号 1 ～ N）・無向・連結・閉路なし** の木専用。

## 考え方：BFS を2回

1. 頂点 `1` から BFS（幅優先探索）し、最も遠い頂点 `u` を探す。
2. `u` から BFS し、最も遠い頂点 `v` を探す。
3. `u` から `v` までの距離が直径。親を逆にたどれば経路も復元できる。

木では、どの頂点から始めても「最も遠い頂点」はある直径の端点になる。同距離の頂点が複数あれば、どれを選んでもよい。
一般の閉路を含むグラフにこの性質はない。

- **時間計算量**: `O(N)`（辺は `N - 1` 本。BFS は各2回）
- **追加空間計算量**: `O(N)`
- `N = 1` の直径は `0`（経路は `{1}`）

## 入力形式（末尾の main）

```text
N
a1 b1
a2 b2
...
a(N-1) b(N-1)
```

例：

```text
6
1 2
2 3
3 4
3 5
2 6
```

出力（直径の **辺数**）:

```text
3
```

## 使い方

`G` は `vector<vector<int>> G(N + 1)` という隣接リスト。各辺 `a-b` は **両方向** に追加する。

```cpp
auto result = tree_diameter(G);
cout << result.length << '\n';      // 直径の長さ（辺数）
cout << result.length + 1 << '\n';  // 直径上の頂点数
cout << result.u << ' ' << result.v << '\n'; // 両端点
for (int x : result.path) cout << x << ' '; // u から v の経路
```

- `tree_diameter(G)`（木の直径と経路を計算する関数）: `TreeDiameterResult`（計算結果）を返す。
- `result.length`（辺数で測った直径）
- `result.u`, `result.v`（直径の両端点）
- `result.path`（端点を含む経路上の頂点列）
- `tree_bfs(G, start)`（ある頂点から BFS して距離・親・最遠点を求める関数）は内部で使用。

**注意**: 辺に重みがある木では、このまま使えない。重み付き木は距離の加算を変更して別実装にすること（負の重みがある場合、2回の最遠点探索そのものにも注意が必要）。
`main()` 付きなので、このファイルをそのまま単独コンパイルできる。既存の `main()` に部品として貼り付ける場合は、このファイル末尾の `main()` を除く。
